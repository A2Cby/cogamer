# 📋 Полный анализ проекта **Cogamer**

## 🎯 Общее описание проекта

**Cogamer** — это умный игровой ассистент с искусственным интеллектом, который анализирует геймплей в реальном времени и предоставляет голосовые советы и стратегические рекомендации игроку.

---

## 📁 Главные файлы проекта

### 1️⃣ **`cogamer.py`** — ГЛАВНЫЙ ФАЙЛ ПРОЕКТА ⭐

Это основной исполняемый файл, содержащий всю логику приложения.

#### 🔑 Ключевые компоненты:

#### **Класс `GlobalContext`** (строки 58-98)
Глобальный контекст для хранения состояния приложения:
- `conversation_history` — история диалога с пользователем
- `user_preferences` — пользовательские настройки
- `game` — название обнаруженной игры
- `category` — категория игры
- `focus_points` — ключевые точки внимания для анализа
- `notes` — глобальные заметки
- `frame_analysis_results` — результаты анализа кадров

**Методы:**
- `add_message()` — добавляет сообщение в историю
- `get_history()` — получает историю
- `set_preference()` / `get_preference()` — управление настройками
- `to_json()` — экспорт в JSON

---

#### **Класс `Agent`** (строки 265-667) — Основной агент
Главный класс приложения, управляющий всей функциональностью.

##### 🎤 Методы захвата и обработки:

1. **`_capture_screen_frame()`** (строки 359-374)
   - Захватывает скриншот экрана
   - Конвертирует в base64 JPEG
   - Оптимизирует размер до 1024×1024

2. **`stream_screen_frames()`** (строки 377-402)
   - Непрерывно захватывает кадры экрана (каждые 1 сек)
   - Отправляет кадры в WebSocket
   - Каждые 30 кадров запускает фоновый анализ

3. **`listen_audio()`** (строки 443-473)
   - Захватывает аудио с микрофона
   - Отправляет в WebSocket для обработки
   - Использует PyAudio

4. **`receive_audio()`** (строки 492-535)
   - Получает голосовые ответы от AI
   - Декодирует аудио из base64
   - Управляет визуализацией (речь/тишина)
   - Обрабатывает вызовы инструментов

5. **`play_audio()`** (строки 542-559)
   - Воспроизводит полученные аудио-ответы

---

##### 🧠 Методы анализа:

6. **`run_background_analysis()`** (строки 405-440)
   - Анализирует последние 10 из 30 кадров
   - Вызывает `analyze_frame()` через OpenAI GPT-4
   - Сохраняет результаты в JSON файлы
   - Обновляет глобальный контекст

7. **`send_text()`** (строки 314-357)
   - Обрабатывает текстовый ввод пользователя
   - Формирует промпты с контекстом анализа
   - Отправляет запросы в Gemini AI
   - При вводе "q" генерирует финальный отчет

8. **`periodic_context_update()`** (строки 562-580)
   - Обновляет контекст каждую минуту
   - Суммирует результаты анализа

9. **`generate_final_report()`** (строки 583-598)
   - Генерирует итоговый отчет сессии
   - Сохраняет в `data/summary_reports/end_report.txt`

---

##### ⚙️ Системные методы:

10. **`startup()`** (строки 284-310)
    - Инициализирует WebSocket соединение
    - Настраивает модель Gemini
    - Устанавливает голос, инструменты

11. **`send_realtime()`** (строки 476-489)
    - Отправляет медиа-потоки в реальном времени

12. **`run()`** (строки 634-666)
    - Запускает все асинхронные задачи
    - Управляет жизненным циклом агента

---

#### 🛠️ Функции анализа (вне класса):

13. **`detect_game_and_focus_points()`** (строки 102-125)
    - Анализирует кадры для определения игры
    - Выявляет ключевые точки фокуса
    - Использует GPT-4 с vision

14. **`analyze_frame()`** (строки 128-157)
    - Детально анализирует партию кадров (10 шт)
    - Выявляет трюки, ошибки, оптимизации
    - Возвращает структурированный результат

15. **`summarize_results()`** (строки 160-174)
    - Суммирует все результаты анализа
    - Формирует JSON-отчет

16. **`generate_end_report()`** (строки 177-195)
    - Создает финальный текстовый отчет
    - С рекомендациями и выводами

---

#### 🔧 Обработчики инструментов:

17. **`save_user_preferences()`** (строки 202-206)
    - Сохраняет настройки в файл

18. **`remember_user_preferences()`** (строки 209-212)
    - Запоминает настройки в памяти

19. **`perform_game_detection()`** (строки 215-221)
    - Запускает определение игры

20. **`handle_tool_call()`** (строки 223-259)
    - Обрабатывает вызовы инструментов от Gemini

## 🎮 Точка входа

**Функция `cogamer()`** (строки 668-673)
- Создает экземпляр `Agent`
- Запускает асинхронное выполнение

**Блок `if __name__ == "__main__":`** (строки 679-688)
- Создает межпроцессное соединение (Pipe)
- Запускает видеоплеер в отдельном процессе
- Запускает основного агента

### 2️⃣ **`main.py`** — GUI выбора голоса

Простой интерфейс Tkinter для выбора голоса ассистента перед запуском.

#### Класс `ChooseLanguageWindow`:
- **`__init__()`** — создает окно с выбором голоса
- **`run()`** — запускает GUI
- **`select()`** — обновляет выбранный голос
- **`start_cogamer()`** — запускает cogamer с выбранным голосом
- **`exit_from_app()`** — закрывает приложение

**Доступные голоса:** Puck, Charon, Kore, Fenrir (по умолчанию), Aoede

---

### 3️⃣ **`schemas.py`** — Структуры данных (Pydantic)

#### Модели:

1. **`FrameAnalysis`** — результат анализа кадра
   - `comments` — общие комментарии
   - `recommendations` — рекомендации
   - `tricks_used` — использованные трюки
   - `good_actions` — хорошие действия
   - `bad_actions` — ошибки
   - `new_notes` — новые глобальные заметки

2. **`Context`** — контекст анализа
   - `game` — название игры
   - `category` — категория
   - `focus_points` — точки фокуса
   - `notes` — заметки

3. **`DetectGameFocusPoints`** — результат определения игры
   - `game` — название игры
   - `focus_points` — ключевые точки

---

### 4️⃣ **`video_player.py`** — Визуальный аватар

Отображает анимированного персонажа, который "говорит" и "молчит".

#### Класс `VideoPlayer`:
- **`_setup_ui()`** — настраивает размер окна (1/16 экрана)
- **`_load_and_preprocess_videos()`** — загружает и масштабирует видео
- **`_update_frame()`** — обновляет кадры (каждые 20 мс)
- **`_switch_video()`** — переключает между режимами (речь/тишина)
- **`run()`** — запускает плеер

**Видео-режимы:**
- `SILENCE` — персонаж в покое
- `SPEECH` — персонаж говорит

---

### 5️⃣ **`ws_client.py`** — WebSocket клиент

Надежный WebSocket клиент с автоматическим переподключением.

#### Класс `WebSocketClient`:
- **`init_connect()`** — инициализация и запуск менеджера
- **`connect()`** — установка соединения
- **`reconnect()`** — переподключение
- **`disconnect()`** — отключение
- **`send()` / `receive()`** — отправка/получение с проверкой
- **`force_send()` / `force_receive()`** — с автопереподключением
- **`_connection_manager()`** — фоновый менеджер соединения

**Особенности:**
- Экспоненциальная задержка при переподключении
- Потокобезопасность (asyncio.Lock)
- SSL с отключенной верификацией

---

### 6️⃣ **`containers.py`** — Dependency Injection

Контейнер зависимостей (dependency-injector).

#### `CogamerContainer`:
- `logger` — логгер
- `ws_client` — синглтон WebSocket клиента

---

### 7️⃣ **`prompts/prompts.py`** — Промпты и инструменты

#### Константы:

  - Задает цели взаимодействия

- **`tools_custom`** — набор инструментов для Gemini
  - `save_user_preferences` — сохранение настроек
  - `remember_user_preferences` — запоминание настроек
  - `perform_game_detection` — определение игры

## 🧩 Используемые технологии

### AI/ML:
- **Google Gemini 2.0 Flash** — основной AI (через WebSocket)

- **OpenCV (cv2)** — масштабирование видео

### Интерфейс:
- **Tkinter** — GUI
- **multiprocessing** — отдельный процесс для видео

### Другое:
- **asyncio** — асинхронное выполнение
- **websockets** — WebSocket клиент
- **Pydantic** — валидация данных

## 📊 Ключевые особенности

1. **Реал-тайм мультимодальность**: захват экрана + аудио одновременно
2. **Двойной AI анализ**: 
   - Gemini для интерактивных советов
   - GPT-4 для глубокого анализа кадров
3. **Персистентность**: сохранение анализа и отчетов в JSON/TXT
4. **Визуальный аватар**: анимированный персонаж реагирует на речь
5. **Автоматическое переподключение**: устойчивость к сетевым сбоям
6. **Периодический анализ**: каждые 30 секунд + итоговый отчет

---

## 🎯 Основной рабочий цикл

1. **Запуск** → выбор голоса в GUI
2. **Инициализация** → подключение к Gemini WebSocket
3. **Мониторинг**:
   - Захват экрана (1 FPS)
   - Захват аудио с микрофона
   - Отправка в Gemini
4. **Фоновый анализ** (каждые 30 сек):
   - Анализ последних 10 кадров через GPT-4
   - Сохранение результатов
5. **Взаимодействие**:
   - Голосовые ответы от Gemini
   - Текстовые команды от пользователя
6. **Завершение** (ввод "q"):
   - Генерация итогового отчета
   - Сохранение всех данных
