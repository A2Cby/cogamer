# 🚀 Быстрый старт: Система сохранения контекста

## Что было сделано?

Реализована автоматическая система сохранения и восстановления контекста диалога между переподключениями ассистента.

---

## ✅ Как это работает (автоматически!)

### 1. При работе приложения
- Ассистент отслеживает все реплики игрока
- Ассистент сохраняет свои ответы в историю диалога
- Всё происходит незаметно в фоновом режиме

### 2. При переподключении (каждые 7 минут)
- **Автоматически сохраняются** последние 3 пары реплик в `data/conversation_context.json`
- Создается новое WebSocket соединение
- **Автоматически загружается** сохраненный контекст
- Контекст передается ассистенту через системные инструкции

### 3. Результат
🎉 **Ассистент продолжает диалог естественно, как будто ничего не произошло!**

---

## 📁 Где хранится контекст?

Файл: `data/conversation_context.json`

Пример содержимого:
```json
{
  "recent_conversation": [
    ["user", "Как мне пройти этот уровень?"],
    ["assistant", "Попробуй использовать щит в момент атаки."],
    ["user", "Спасибо! А что дальше?"],
    ["assistant", "Иди налево к сундуку."],
    ["user", "Нашел ключ!"],
    ["assistant", "Отлично! Открой дверь справа."]
  ],
  "game": "Dark Souls III",
  "category": "Speedrun Analysis",
  "timestamp": "2025-10-14T15:42:33.123456"
}
```

## 🐛 Решение проблем

### Контекст не восстанавливается?

1. Проверьте наличие файла `data/conversation_context.json`
2. Проверьте логи на наличие ошибок при загрузке
3. Убедитесь, что файл содержит валидный JSON

### Файл не создается?

1. Убедитесь, что папка `data/` существует (создается автоматически)
2. Проверьте права на запись в папку проекта
3. Проверьте логи на наличие ошибок при сохранении

### Ассистент всё равно забывает контекст?

1. Убедитесь, что в логах есть сообщение: `"Восстановлено N реплик"`
2. Проверьте, что переподключение происходит корректно
3. Увеличьте количество сохраняемых пар реплик
