┌───────────────────────────────────────────────────────────────┐
│  🔍 ЧТО ПРОИСХОДИТ ПОД КАПОТОМ?                               │
└───────────────────────────────────────────────────────────────┘

1. Вы общаетесь с ассистентом → реплики сохраняются в памяти
2. Проходит 7 минут → срабатывает автоматическое переподключение
3. ПЕРЕД переподключением:
   ✅ Последние 6 реплик сохраняются в файл
4. ПРИ переподключении:
   ✅ Контекст загружается из файла
   ✅ Передается ассистенту в системных инструкциях
5. Вы продолжаете диалог → ассистент ПОМНИТ контекст! 🎉


┌───────────────────────────────────────────────────────────────┐
│  📁 ГДЕ ХРАНИТСЯ КОНТЕКСТ?                                    │
└───────────────────────────────────────────────────────────────┘

Файл: data/conversation_context.json

Пример содержимого:
{
  "recent_conversation": [
    ["user", "Как пройти этот уровень?"],
    ["assistant", "Попробуй использовать щит..."],
    ["user", "Спасибо! А что дальше?"],
    ["assistant", "Иди налево к сундуку..."],
    ...
  ],
  "game": "Dark Souls III",
  "timestamp": "2025-10-14T15:42:33"
}


┌───────────────────────────────────────────────────────────────┐
│  📊 ТЕХНИЧЕСКИЕ ДЕТАЛИ                                        │
└───────────────────────────────────────────────────────────────┘

• Количество сохраняемых реплик: 6 (3 пары игрок-ассистент)
• Интервал переподключения: 7 минут
• Формат хранения: JSON (UTF-8, поддержка кириллицы)
• Обработка ошибок: Да (программа не упадет при проблемах)
• Логирование: Полное (все операции записываются в лог)

Хотите сохранять больше/меньше реплик?

Откройте cogamer.py, найдите строку ~106:
  "recent_conversation": self.get_recent_conversation(num_pairs=3)
  
Измените 3 на нужное число (например, 5 для 10 реплик)

Хотите изменить интервал переподключения?

Откройте cogamer.py, найдите строку ~266:
  RECONNECTION_INTERVAL = 60*7  # 7 минут
  
Измените 7 на нужное количество минут

❓ Контекст не восстанавливается?
  → Проверьте наличие файла data/conversation_context.json
  → Проверьте логи на наличие ошибок

❓ Файл не создается?
  → Проверьте права на запись в папку data/
  → Папка создается автоматически, но может быть блокирована

❓ Ассистент всё равно забывает?
  → Убедитесь в логах: "Восстановлено N реплик"
  → Увеличьте num_pairs в настройках
